---
title: 'Privacy'
description: 'Analytics, browser storage, and search data on this site.'
---

This site uses [Umami](https://umami.is/) for basic traffic statistics when enabled, as indicated above. Your browser sends page paths, titles, referrers, browser and device information, and approximate location to Umami Cloud to help us understand readership. The tracker uses no cookies. We do not set user IDs or enable session replay.

Page URL query parameters and fragments are excluded from analytics. We send no custom search events. Full-text search reads a static index in your browser without submitting search terms to Umami or a local LLM. Tracking stops when the browser exposes an enabled Do Not Track signal. Content blockers can also block the tracker.

Your theme preference is stored locally under `blog.tech.theme` and can be cleared in browser settings. No login is required; comments are disabled.

Cloudflare hosts this site. Hosting and analytics providers still process network requests and IP addresses, including for approximate location and potentially operational or security logs. Those logs are separate from analytics records. See [Umami’s privacy policy](https://umami.is/privacy) and [data FAQ](https://docs.umami.is/docs/faq). You can contact the author through [J. Kong’s portfolio](https://portfolio.fnpg.me/).
